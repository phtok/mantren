# Guide — modifier la traduction française en ligne

*Pour Louis Defèche · site Mantren (GA 270)*

Tu peux désormais **modifier directement ta traduction française** sur le site,
sans compte ni logiciel. Il te suffit d'un lien secret personnel.

---

## 1. Ton lien secret

Philipp te transmet un lien personnel de la forme :

```
https://phtok.github.io/mantren/<mantra>/?edit=<TON-JETON>
```

- **Garde ce lien comme un mot de passe.** Quiconque le possède peut modifier la
  traduction. Ne le publie pas, ne le partage pas.
- S'il venait à fuiter, on le remplace en quelques secondes (nouveau jeton) —
  préviens simplement Philipp.

---

## 2. Modifier un mantra

1. Ouvre ton lien (par exemple pour le mantra 4 :
   `…/mantren/4/?edit=<TON-JETON>`).
2. Le site passe en **mode français** et fait apparaître, sur la page, un champ
   d'édition **« Modifier »** contenant ta traduction actuelle.
3. Corrige le texte librement dans le champ.
4. Clique sur **« Enregistrer »**. La mention **« Enregistré »** confirme la
   sauvegarde.

C'est tout. Ta nouvelle version est **immédiatement visible** pour tous les
lecteurs en mode français.

### Mise en forme
- **Une ligne = un vers.**
- **Une ligne vide = une séparation de strophe** (un espacement entre les blocs).

---

## 3. Passer d'un mantra à l'autre

- Utilise les flèches **← / →** en bas de page (ou glisse à gauche/droite sur
  mobile) : ton mode édition **reste actif** d'un mantra au suivant.
- Ou change directement le numéro dans l'adresse : `…/mantren/4/…` →
  `…/mantren/5/…`.

Identifiants des mantras : les tables `erste-tafel`, `zweite-tafel`,
`dritte-tafel` ; les mantras `2`, `3`, `4`, … ; les sous-parties `1.1`–`1.4`,
`7.1`–`7.3`, `9.1`, `9.2`, `11.1`–`11.3`, `12.1`, `12.2`, `14.1`–`14.4`,
`15.1`–`15.3`, `16.1`, `16.2`, `19.1`–`19.3` ; le mantra final `19+`.

---

## 4. Bon à savoir

- **Chaque enregistrement est conservé** (historique daté) : rien n'est perdu,
  on peut revenir à un état antérieur.
- **Sans ton lien**, personne ne voit de champ d'édition ; les lecteurs voient
  seulement ta traduction publiée.
- **Hors ligne**, le site montre la dernière version publiée — l'édition demande
  une connexion.
- Le texte allemand original (Rudolf Steiner) reste à gauche ; ta traduction
  s'affiche à côté.

En cas de doute ou de problème, écris à Philipp.
